## 📌 Sobre a disciplina

A disciplina introduz a lógica de programação e o desenvolvimento de algoritmos fundamentais em C++: variáveis, operadores, estruturas de decisão e de repetição, vetores e funções.

---

## 📚 Conteúdo da disciplina

| # | Assunto | Tópicos |
|---|---|---|
| 01 | Variáveis | Entrada e saída, tipos de dados, cálculos simples |
| 02 | Operadores aritméticos | Operações básicas, conversão de graus para radianos, seno, cosseno e raiz quadrada |
| 03 | Estrutura de decisão | `if`, `else`, `switch`, exercícios do Beecrowd |
| 04 | Estrutura de repetição | `for`, `while`, somas, médias e maiores valores |
| 05 | Vetores | Armazenamento de notas, média e maior nota da turma |
| 06 | Funções | Calculadora, números ímpares |

## 💡 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/carolferreira-dev/c02_algoritmos_e_estrutura_de_dados_I.git
   ```

2. Entre na pasta desejada:
   ```bash
   cd c02_algoritmos_e_estrutura_de_dados_I/slides_estrutura_decisao
   ```

3. Compile o código:
   ```bash
   g++ idade_categoria.cpp -o executavel
   ```

4. Execute o programa:
   ```bash
   ./executavel        # Linux/Mac
   executavel.exe      # Windows
   ```
